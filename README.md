### Projeto Mini CRUD de Produtos ###

Integrante:
Nome: Evellyn Valencia

----------------------------------------

Descrição do Projeto:
Este projeto consiste em uma aplicação desktop desenvolvida em C# utilizando Windows Forms, com o objetivo de implementar um sistema simples de gerenciamento de produtos.

----------------------------------------

Como executar a aplicação:
1. Abrir o projeto no Visual Studio.
2. Localizar o arquivo da solução (.sln).
3. Executar o projeto pressionando F5 ou clicando em "Iniciar".
4. A aplicação será aberta com a interface gráfica pronta para uso.

----------------------------------------

Funcionalidades implementadas:
- Cadastro de produtos (ID, nome, preço e quantidade)
- Listagem de produtos cadastrados
- Busca de produto por ID
- Atualização da quantidade em estoque
- Cálculo do valor total em estoque (preço × quantidade)
- Validação de dados de entrada
- Tratamento de erros (entrada inválida e produto não encontrado)
- Ordenação dos produtos por ID na listagem

----------------------------------------

Observações adicionais:
Durante o desenvolvimento, foram utilizados conceitos fundamentais de programação, como estruturas de repetição, condicionais e manipulação de listas.

Os dados são armazenados em memória, simulando um banco de dados.

Como melhoria futura, a aplicação pode ser integrada a um banco de dados SQL para permitir persistência dos dados.
